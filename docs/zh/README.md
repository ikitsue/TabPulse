# 📊 TabPulse - Chrome Manifest V3 扩展

一个简单轻巧的扩展程序，用于跟踪您的浏览统计数据。

## 📋 项目文件

### 1. **manifest.json**
扩展的配置（Chrome 必需）。

**它做什么：**
- 声明扩展的名称、版本和描述
- 列出所需的权限（`tabs`、`webNavigation`、`storage`）
- 指向 Service Worker（`background.js`）
- 配置弹出窗口（`popup.html`）

**关键点：** `manifest_version: 3` = Manifest V3（新标准）

---

### 2. **background.js**
在后台运行并管理逻辑的 Service Worker。

**它做什么：**
- 🕐 **初始化会话** → 记录浏览器启动时间
- 📄 **计算页面** → 使用 `chrome.webNavigation.onCommitted` 检测每个新页面
- 🚫 **避免重复** → 将当前 URL 与上一个进行比较
- 💾 **存储数据** → 使用 `chrome.storage.local`（本地存储，从不发送）
- 📨 **与弹出窗口通信** → 用统计数据响应弹出窗口的消息

**关键事件：**
- `chrome.webNavigation.onCommitted` → 页面加载时触发
- `chrome.runtime.onMessage` → 接收来自弹出窗口的请求

---

### 3. **popup.html**
用户界面（单击图标时看到的内容）。

**它显示：**
- ⏱️ 自浏览器启动以来经过的时间（以分钟为单位）
- 📊 浏览的总页数
- 🎨 带有紫色渐变的现代设计

---

### 4. **popup.js**
弹出窗口逻辑。

**它做什么：**
- 🔄 每秒从后台获取统计数据
- 📝 以可读方式格式化数字
- ✨ 实时更新界面

---

### 5. **options.html / options.js**
用于更改语言的设置页面。

**它做什么：**
- 🌍 在 5 种语言之间选择（英文、法文、俄文、西班牙文、中文）
- 💾 保存您的首选项
- 🔄 即时翻译整个扩展

---

### 6. **i18n.js**
翻译系统。

**包含：**
- 5 种语言的所有文本
- 加载和应用翻译的函数
- 实时语言切换

---

## 🚀 如何加载扩展

### 第 1 步：打开扩展页面
1. 打开 **Chrome** 或 **Brave**
2. 转到：`chrome://extensions/`（Chrome）或 `brave://extensions/`（Brave）

### 第 2 步：启用开发者模式
- 单击 **"开发者模式"** 开关（右上角）

### 第 3 步：加载扩展
1. 单击 **"加载未打包的扩展程序"**
2. 选择包含扩展文件的文件夹
3. ✅ 扩展已加载！

### 第 4 步：测试扩展
- 您将在工具栏中看到扩展图标
- 单击它打开弹出窗口
- 每访问一个新页面，统计数据都会增加
- 单击 ⚙️ 设置以更改语言

---

## 🔐 隐私

✅ **此扩展：**
- ❌ 从不记录 URL
- ❌ 从不记录页面标题
- ❌ 从不记录历史记录
- ✅ 仅计算页面（原始数字，无详细信息）
- ✅ 数据保留在浏览器本地存储中
- ✅ 不向网络发送任何内容

---

## 📈 它如何工作（详细）

```
用户单击一个页面
         ↓
background.js 检测到 onCommitted 事件
         ↓
将 URL 与上一个进行比较以避免重复
         ↓
增加页面计数器
         ↓
用户打开弹出窗口
         ↓
popup.js 从后台请求统计数据
         ↓
background.js 发送：经过的时间 + 页数
         ↓
popup.js 显示更新的统计数据
         ↓
弹出窗口每秒更新一次（计时器）
```

---

## 💾 存储的数据

扩展在 `chrome.storage.local` 中存储 4 个密钥：

| 密钥 | 值 | 示例 |
|-------|-------|---------|
| `sessionStartTime` | 浏览器启动时间戳 | `1715000000000` |
| `pageCount` | 浏览的页数 | `42` |
| `lastUrl` | 上一个 URL 以避免重复 | `https://google.com` |
| `language` | 当前语言 | `zh` |
