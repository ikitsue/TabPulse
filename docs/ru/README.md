# 📊 TabPilse - Расширение Chrome Manifest V3

Простое и легкое расширение для отслеживания статистики вашего просмотра.

## 📋 Файлы проекта

### 1. **manifest.json**
Конфигурация расширения (требуется Chrome).

**Что он делает:**
- Объявляет имя, версию и описание расширения
- Перечисляет необходимые разрешения (`tabs`, `webNavigation`, `storage`)
- Указывает на Service Worker (`background.js`)
- Настраивает всплывающее окно (`popup.html`)

**Ключевой момент:** `manifest_version: 3` = Manifest V3 (новый стандарт)

---

### 2. **background.js**
Service Worker, работающий в фоне и управляющий логикой.

**Что он делает:**
- 🕐 **Инициализирует сеанс** → Записывает время запуска браузера
- 📄 **Подсчитывает страницы** → Использует `chrome.webNavigation.onCommitted` для обнаружения каждой новой страницы
- 🚫 **Избегает дубликатов** → Сравнивает текущий URL с предыдущим
- 💾 **Хранит данные** → Использует `chrome.storage.local` (локальное хранилище, никогда не отправляется)
- 📨 **Обменивается данными с всплывающим окном** → Отвечает на сообщения с статистикой

**Ключевые события:**
- `chrome.webNavigation.onCommitted` → Срабатывает при загрузке страницы
- `chrome.runtime.onMessage` → Получает запросы из всплывающего окна

---

### 3. **popup.html**
Пользовательский интерфейс (то, что вы видите при нажатии на значок).

**Что он отображает:**
- ⏱️ Время, прошедшее с момента запуска браузера (в минутах)
- 📊 Общее количество просмотренных страниц
- 🎨 Современный дизайн с фиолетовым градиентом

---

### 4. **popup.js**
Логика всплывающего окна.

**Что он делает:**
- 🔄 Получает статистику из фонового каждую секунду
- 📝 Форматирует числа в удобный вид
- ✨ Обновляет интерфейс в реальном времени

---

### 5. **options.html / options.js**
Страница настроек для изменения языка.

**Что она делает:**
- 🌍 Выбор между 5 языками (Английский, Французский, Русский, Испанский, Китайский)
- 💾 Сохранение вашего предпочтения
- 🔄 Мгновенный перевод всего расширения

---

### 6. **i18n.js**
Система перевода.

**Содержит:**
- Все тексты на 5 языках
- Функции для загрузки и применения переводов
- Переключение языка в реальном времени

---

## 🚀 Как загрузить расширение

### Шаг 1: Откройте страницу расширений
1. Откройте **Chrome** или **Brave**
2. Перейдите на: `chrome://extensions/` (Chrome) или `brave://extensions/` (Brave)

### Шаг 2: Включите режим разработчика
- Нажмите на переключатель **"Режим разработчика"** (верхний правый угол)

### Шаг 3: Загрузите расширение
1. Нажмите **"Загрузить распакованное расширение"**
2. Выберите папку с файлами расширения
3. ✅ Расширение загружено!

### Шаг 4: Протестируйте расширение
- Вы увидите значок расширения в панели инструментов
- Нажмите на него, чтобы открыть всплывающее окно
- Статистика будет увеличиваться с каждой новой страницей
- Нажмите ⚙️ Настройки, чтобы изменить язык

## 🔐 Конфиденциальность

✅ **Это расширение:**
- ❌ НИКОГДА не записывает URL
- ❌ НИКОГДА не записывает названия страниц
- ❌ НИКОГДА не записывает историю
- ✅ Только подсчитывает страницы (сырое число, без деталей)
- ✅ Данные остаются в локальном хранилище браузера
- ✅ Ничего не отправляется в интернет

---

## 📈 Как это работает (подробно)

```
Пользователь нажимает на страницу
         ↓
background.js обнаруживает событие onCommitted
         ↓
Сравнивает URL с предыдущим, чтобы избежать дубликатов
         ↓
Увеличивает счетчик страниц
         ↓
Пользователь открывает всплывающее окно
         ↓
popup.js запрашивает статистику из фона
         ↓
background.js отправляет: прошедшее время + количество страниц
         ↓
popup.js отображает обновленную статистику
         ↓
Всплывающее окно обновляется каждую секунду (таймер)
```

## 💾 Сохраненные данные

Расширение хранит 4 ключа в `chrome.storage.local`:

| Ключ | Значение | Пример |
|-----|---------|---------|
| `sessionStartTime` | Временная метка запуска браузера | `1715000000000` |
| `pageCount` | Количество просмотренных страниц | `42` |
| `lastUrl` | Последний URL для избежания дубликатов | `https://google.com` |
| `language` | Текущий язык | `ru` |
