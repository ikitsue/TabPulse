# Структура проекта - TabPilse

```
TabPilse/
├── manifest.json          # Конфигурация расширения
├── background.js          # Service Worker (основная логика)
├── popup.html             # Интерфейс всплывающего окна
├── popup.js               # Логика всплывающего окна
├── options.html           # Страница настроек
├── options.js             # Логика настроек
├── i18n.js                # Система перевода
├── README.md              # Основная документация (многоязычная)
├── LICENSE                # Лицензия MIT
├── .gitignore             # Файл исключения Git
├── docs/                  # Документация по языкам
│   ├── en/
│   │   ├── README.md
│   │   └── STRUCTURE.md
│   ├── fr/
│   │   ├── README.md
│   │   └── STRUCTURE.md
│   ├── ru/
│   │   ├── README.md
│   │   └── STRUCTURE.md
│   ├── es/
│   │   ├── README.md
│   │   └── STRUCTURE.md
│   └── zh/
│       ├── README.md
│       └── STRUCTURE.md
├── images/                # Папка для иконок (опционально)
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── DOCUMENTATION_ALL.md   # Полная документация в одном файле
```

## Примечания по организации

- **manifest.json** : Проверьте разрешения при необходимости
- **background.js** : Деловая логика (где добавлять новые функции)
- **popup.html/js** : Пользовательский интерфейс (где изменять отображение)
- **options.html/js** : Страница настроек (язык, будущие предпочтения)
- **i18n.js** : Система перевода (добавьте новые языки здесь)
- **docs/** : Документация по языкам (организована по кодам языков)
- **images/** : Поместите ваши PNG иконки (16x16, 48x48, 128x128)

Структура минималистична, но легко расширяется для будущего развития.
